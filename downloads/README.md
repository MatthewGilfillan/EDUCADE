# Cloudflare website upload

Download the file EDUCADE-cloudflare-upload.zip in this folder using its
View raw / Download raw file link. It contains only the website files,
with index.html and teacher.html at the archive root.

In Cloudflare, remove the previous upload selection before choosing this ZIP.
If choosing files individually, unzip it and select all files and folders inside.

To preview locally, unzip it and open teacher.html.

Use the individual ZIP file link. GitHub's green Code / Download ZIP button
downloads the whole repository, including its development configuration.

This download branch does not change the development or production branches.
