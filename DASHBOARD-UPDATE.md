# Adaptive reading and curriculum dashboard

Open `public/teacher.html` in a browser. Select a learner's profile to open the Overall radar; switch subjects for individual skills and evidence.

## Included

- Overall radar showing Reading, Writing, Grammar and Vocabulary from existing fictional evidence, with speaking/listening explicitly unassessed.
- Four-week practice progress beside the radar and Glows & Grows beneath the graph.
- Provisional EDUCADE reading bands, starting level and illustrative easier/stretch text. Bands are independent fictional fixtures, not Lexile scores or grade equivalents.
- Curriculum selector: Common Core Grade 5; England Upper KS2 Years 5–6; Australian Curriculum English v9 Year 5; Cambridge Primary English (0058), Stage 5.
- Skill-level curriculum context and source links. Common Core retains existing partial mappings. England links are candidates. Australian and Cambridge links are thematic, awaiting objective-level review. No one-to-one equivalence is claimed.
- Keyboard-operable radar points, browser-saved curriculum choice, existing portraits, class controls and evidence dialogs.

## Future work

Placement assessment, live adaptive text delivery, validated Lexile assessment, student accounts, reviewed year-specific curriculum mapping, and Cambridge English as a Second Language are future features. All student records and reading bands in this download are fictional. The reading preview demonstrates design intent rather than a working assessment algorithm.

## Packaging

The downloadable ZIP contains the complete static website under `website/`, editable source and test files under `source/`, and a `START-HERE.html` dashboard launcher. It excludes Git metadata, dependencies, build output and credentials.
